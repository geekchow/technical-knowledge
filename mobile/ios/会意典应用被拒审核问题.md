几个容易踩坑的地方：

**Build Number 必须递增** — Version 可以和上次一样（比如都是 1.0.1），但 Build 号必须比之前所有上传过的构建版本都大，否则 Xcode 上传会直接报错。

I removed the app from applestore connect, then want to create a new one, so I have to use a new bundle id?

---

**Claude**

No, you don't have to. Here's the full picture:

**If you "removed" the app by deleting it from App Store Connect**, the bundle ID gets released back and you can reuse it — but there's a catch: you need to first delete it from the Identifiers list in the Apple Developer Portal, then re-register it. Or you can simply create a new app in App Store Connect using that same bundle ID directly (ASC will find it in your portal).

**The exact behavior depends on how you removed it:**

| Action | Bundle ID status | Can reuse? |
| --- | --- | --- |
| Removed app from ASC (never went live) | Still registered in Developer Portal | Yes, reuse directly |
| App was live then removed | Still registered | Yes, reuse directly |
| Deleted from both ASC + Developer Portal | Fully released | Yes, re-register then use |

**Practical steps to reuse the same bundle ID:**

1. Go to [developer.apple.com](https://developer.apple.com/) → **Certificates, Identifiers & Profiles** → **Identifiers**
2. Check if your old bundle ID (e.g. `com.yourname.huiyidian`) still exists there
3. If yes → go straight to App Store Connect → **My Apps** → **+** → **New App** → select that existing bundle ID
4. If it was deleted → register it again first, then create the app in ASC

**When you'd actually need a new bundle ID:**

- You want to publish it as a completely separate app (different listing, different name)
- The old app was live and had purchases — reusing the bundle ID would inherit its review history and ratings, which could be good or bad

In your case (会意典, never successfully went live), reusing the same bundle ID is perfectly fine and saves you from updating all your code references.

That's expected — when you deleted the app from ASC, the bundle ID was also removed from your Developer Portal. You need to re-register it first, then it'll appear in the dropdown.

**Step 1 — Re-register the bundle ID in Developer Portal**

1. Go to [developer.apple.com/account](https://developer.apple.com/account) → **Certificates, Identifiers & Profiles** → **Identifiers**
2. Click **+** to register a new identifier
3. Select **App IDs** → **App** → Continue
4. Fill in:
	- **Description**: 会意典 (anything)
		- **Bundle ID**: select **Explicit** → type your exact old bundle ID (e.g. `com.yourname.huiyidian`)
5. Scroll down, enable the same **Capabilities** your app uses (e.g. In-App Purchase, Push Notifications if any)
6. Click **Continue** → **Register**

**Step 2 — Back to ASC New App form**

Refresh the page — your bundle ID will now appear in the dropdown list. Select it and continue filling the form.

**For SKU** — this is just an internal identifier for your own reference, not user-visible. You can use anything unique like `huiyidian-001` or just your bundle ID without the dots `comyournamehuiyidian`.
