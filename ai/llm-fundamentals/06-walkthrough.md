# 06 · 完整重演：带着全部深度，重跑运行示例

> **你在哪里**：终点站。四个深潜已完成，现在把它们缝成一个连续的故事——同一个问题、两个模型，这次每一跳都看到内部。

## 场景重申

笔记本上 ollama 跑着 Llama-3-8B（开源），旁边开着 Claude API（闭源）。同一个问题发给两边：

> "写一个 Python 函数判断质数，并解释为什么只需要检查到平方根。"

## 全深度时间线

### T-6 个月 · 训练侧（深潜 1）

Meta 的集群上：15T token 清洗后的语料以"预测下一个 token"为目标反复冲刷 80 亿个随机初始化的浮点数。GitHub 上无数份 `is_prime` 实现、数学教材里的平方根证明，都在交叉熵损失的驱动下被压进权重。预训练产出只会续写的基座；SFT 教会它"问答格式"；DPO 让它学会人类偏好的回答风格。最终 16 GB 的 safetensors 文件被放上公网——**开源分叉发生**（深潜 4）。同期，Anthropic 的管线做着同样的三级流水，但参数更大、后训练更重，权重留在了自家集群——**闭源分叉**。

### T+0ms · 你按下回车（深潜 2 上场）

两边各自的 tokenizer 把问题切成约 30 个 token ID。本地：ollama 早已把 16 GB 权重载入统一内存。云端：请求经负载均衡落到某张正在跑 continuous batching 的 GPU 上，你的 30 个 token 被拼进当前批次。

### T+50ms · Prefill

30 个 token 一次并行前向：每层算出 Q/K/V，K/V 写入 KV Cache（约 30 × 每 token 缓存量），最后一个 token 位置的概率分布中采样出第一个输出 token。本地 30 个 token 的 prefill 几乎瞬间；Claude 侧模型大得多，但 H100 集群的算力让 TTFT 同样在几百毫秒内。

### T+100ms ~ T+30s · Decode 循环

两边同时进入逐 token 生成：每步读全部权重 + KV Cache → 前向 → 采样 → 新 token 的 K/V 追加进缓存。本地 8B：约 15 token/s（16 GB ÷ MacBook 内存带宽的物理上限，深潜 2 的公式）。Claude：单 token 搬运成本更高，但靠批处理与更快的 HBM 流畅不落下风。你看到两个打字机同时打字。

### 输出对比 · 参数规模显形（深潜 3）

**两边的代码都对**：

```python
def is_prime(n: int) -> bool:
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True
```

高频模式，8B 的容量 + 15T 的超量训练（后 Chinchilla 策略）足以牢固掌握。

**解释分出高下**：8B 给出正确但单薄的一句"因为因子成对出现"；Claude 则完整论证——若 $n = a \times b$ 且 $a \le b$，则 $a \le \sqrt{n}$，故 $\sqrt{n}$ 内无因子即可断定为质数——并自发说明 0、1、负数按定义不是质数、代码为何用 `n < 2` 一并处理。这是深潜 3 的"随规模增强的深层能力"+ 深潜 1 的"后训练深度"共同作用的活标本。

### T+30s · 落幕，两张不同的收据（深潜 4）

- 本地：对话从未离开你的机器，KV Cache 随 ollama 会话释放。成本：几分钱电费。你还保有全部后续权利——明天可以 LoRA 微调它；
- 云端：厂商推理集群释放你的批次槽位，计费系统按输入 30 + 输出约 400 token 记账。你买到了 frontier 质量，交出了数据经手权与每 token 的钱。

## 收束：回到 Stage-1 的问题

[01-why](01-why.md) 的痛点是：任务专用、标注昂贵、零泛化。刚才的 30 秒里——没有人为"质数解释"这个任务标注过一条数据、训练过一个专用模型；一个通用模型靠一句自然语言完成了代码生成+数学论证的复合任务；同一套范式同时以开源和闭源两种形态交付，任你按隐私、成本、能力三轴选择。**Stage-1 的三个痛点，在这个日常到不起眼的场景里被全部解决——这就是 LLM 存在的理由。**
